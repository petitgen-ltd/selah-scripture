    How Selah works

    Three steps, run once a second, entirely in the flow of the workout.

    Sense

    Read the body's moment

    Heart-rate, zone, effort and recovery stream off the wearable. A tiny on-device classifier names the physiological moment — the wall, peak effort, the last rep, the redline, the cool-down.

    trained on the hackathon's biometric movements data
    Discern

    Choose the verse — and how loud

    Each moment maps to Scripture built for it, pulled live in the runner's own language. And Selah chooses the volume: a haptic verse at the wall; a wordless ambient glow at rest. Presence, not interruption.

    via the YouVersion Platform API · 2,000+ languages
    Deliver

    Say it the way a watch would

    A pulse and one line at peak effort. A colour that breathes in the cool-down. And a personal word — shaped by Gloo's faith-tuned model for this person, this moment.

    personalized by the Gloo AI Studio API

    The build

    Real engineering behind the demo.

    Selah turns a biometric stream into a verse delivery. The moment classifier is trained and validated on the provided sessions; verse text is retrieved from YouVersion in any of its 2,000+ languages; and Gloo AI writes the one-line encouragement in a voice tuned for ministry.

    The public notebook runs the exact same pipeline end-to-end — demo mode out of the box, live APIs the moment keys are added. Scripture is served through YouVersion; verse text shown offline here is public-domain. Nothing is faked for the camera.

    # one tick of the loop
    snap = read_wearable() # hr, zone, effort…
    moment = classify_moment(snap) # peak_effort
    verse = youversion.get_verse(pick(moment), lang)
    note = gloo.personalize(moment, verse, user)
    fmt, mode = delivery_for(moment) # haptic / ambient
    watch.deliver(verse, note, fmt, mode)
    # → a pulse + one line, at 178 bpm
