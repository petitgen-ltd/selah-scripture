How Selah works

Three steps, run once a second, entirely in the flow of the workout.

Sense

Read the body's moment

Heart-rate, zone, effort and recovery stream off the wearable. A lightweight classifier names the physiological moment — warm-up, steady state, the wall, peak effort, the finish, the cool-down.

from the hackathon's biometric movements data
Discern

Choose the verse that fits

Each moment maps to Scripture built for it — strength at the wall, endurance at the peak, stillness in recovery. The verse and translation are pulled live in the runner's own language.

via the YouVersion Platform API · 2,000+ languages
Deliver

Say it the way a watch would

Not a pop-up. A haptic pulse and a single line at peak effort; an ambient glow in the cool-down. Gloo's faith-tuned model shapes one short, personal word for this runner, this moment.

personalized by the Gloo AI Studio API

The build

Real engineering behind the demo.

Selah is a client that turns a biometric stream into a verse delivery. The moment classifier is trained on the provided sessions; verse text is retrieved from YouVersion in any of its 2,000+ languages; and Gloo AI writes the one-line encouragement in a voice tuned for ministry — never generic, never off-tone.

The public notebook runs the exact same pipeline end-to-end, in demo mode out of the box and against the live APIs the moment keys are added. Nothing here is faked for the camera.

# one tick of the loop
snap = read_wearable() # hr, zone, effort…
moment = classify_moment(snap) # peak_effort
verse = youversion.get_verse(
  ref=pick(moment), lang=user.lang)
note = gloo.personalize(
  moment, verse, user.history)
watch.deliver(verse, note,
  format=delivery_for(moment))
# → haptic pulse + one line, at 174 bpm
